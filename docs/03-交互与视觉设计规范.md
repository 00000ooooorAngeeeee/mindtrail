# 03 · 交互与视觉设计规范

> 版本：v0.1 ｜ 状态：设计约束草案 ｜ 面向：前端开发、UI 实现 agent

> 说明：本文档给出**信息架构、关键界面结构与交互规则**，不规定像素级视觉稿。前端实现时遵循本文档的布局与交互约定，视觉细节（色值/间距）可微调，但**交互行为与信息层级不得违背**。

## 1. 设计原则

1. **记录优先，成本最低**：任何高频操作（加节点、加记录）≤ 2 次点击或 1 个快捷键
2. **双模式心智统一**：树状与画布是"同一张图的两种视图"，切换不产生新数据
3. **时间线是主角**：过程记录页面信息层级为 时间线 > 条目详情 > Git 提交
4. **本地工具质感**：界面冷静、专注、不花哨；强调信息密度而非装饰
5. **一切皆可搜**：搜索入口全局可达（快捷键直达）

## 2. 信息架构

```
启动器（工作区列表 / 最近打开 / 新建）
 └── 工作区主界面
      ├── 左侧边栏：导图列表 ｜ 会话列表 ｜ 标签 ｜ 工作区设置
      ├── 主内容区（三种视图之一）：
      │    ├── 导图视图（树状模式 / 画布模式，可切换）
      │    └── 会话视图（时间线）
      └── 顶部栏：工作区名 ｜ 全局搜索框 ｜ 模式切换 ｜ 导出菜单
 └── 全局：设置（数据库/主题/仓库路径，M4 任务四落地）、帮助
```

## 3. 关键界面

### 3.1 启动器（首次体验）

- 居中卡片式：**新建工作区**（大按钮）→ 名称 + 描述 + 关联 Git 仓库（可选）
- 下方"最近打开"列表，每项显示名称/更新时间/导图数与会话数
- 首次启动同时出现 MySQL 连接引导（见 E2 需求），可"稍后配置"

### 3.2 工作区主界面（悬浮岛式双列壳层，v1.2 P2 §24 落地）

```
┌─────────────────────────────────────────────────────────────┐
│  ☰ 思迹 TrailMind  后端 vX    [🔍 搜索 Ctrl+K] [⚙ 设置]      │ ← 悬浮岛顶栏
├──────────────┬──────────────────────────────────────────────┤
│ ▾ 项目A      │                                             │
│   ▾ 导图     │            主内容区（右侧悬浮岛）             │
│    · 需求梳理│   导图视图 / 会话卡片标签 / 标签云 / overview  │
│   ▾ 会话     │                                             │
│    ● 会话#1  │                                             │
│    ✓ 会话#2  │                                             │
│   ▸ 标签     │                                             │
│ ▾ 项目B …    │                                             │
│ + 新建工作区 │                                             │
└──────────────┴──────────────────────────────────────────────┘
```

- **悬浮岛式双列**：顶栏 + 左侧侧边栏 + 右侧主内容三块各自为浮岛（card 底 + `--shadow` 投影 + 14px 圆角，外层 12px 留空显浮）
- **左侧可隐藏多级侧边栏**：全部工作区作父节点树，展开 → 导图 / 会话（时间序+状态点，时间轴展示）/ 标签 三组；顶栏 ☰ 按钮可隐藏侧边栏（宽度动画收起）；侧边栏与主区间有拖拽手柄可调节宽度（220–560px，localStorage 持久化，拖拽期禁用过渡）
- 导图/会话点击在右侧显示对应内容（会话保留浏览器式卡片标签切换，v1.1 P1）；标签组点击在右侧显示标签云（`TagSection`）
- 右侧主内容按当前选择切换：overview（工作区元信息+空态引导）｜ 导图（内联右侧编辑，侧边栏常驻可见，不再全屏跳转）｜ 会话卡片标签 ｜ 标签云
- 列表项：标题 + 更新时间（小字）；会话项额外显示状态徽标（进行中●/已完成✓）
- **标签（M4 任务二落地 + v1.1 P1 标签云）**：工作区首页「标签」区列出全部标签（名称 + 使用计数）；顶部**标签云**（v1.1 P1）：按使用计数分档字号（sm/md/lg/xl）、热度降序、循环色板着色，点击即时过滤（与列表同语义）；支持创建/重命名/合并（选择目标标签）/删除/批量合并（v1.2 P2：选 N 个→合并到一个目标，源删除、条目改挂）；点击标签即时过滤出该标签全部条目（工作区级），点击条目跳转对应会话并定位（闪烁，与搜索跳转一致）；会话详情页头部另有「按标签过滤」下拉（会话内过滤）

### 3.3 导图视图（树状模式）

- 画布居中，节点为圆角矩形卡片：文本 + 子节点数徽标（折叠时）+ 折叠图标
- 中心主题最大（字号 18-20），逐级缩小（14/13/12）
- 选中节点：外发光描边 + 浮动工具条（+ 添加子节点 ｜ ✎ 编辑 ｜ 🗑 删除 ｜ 🎨 颜色）
- 快捷键见 §5；折叠/展开用节点左侧的 `▸/▾` 图标
- 底部状态栏：节点数、模式标识、缩放百分比

### 3.4 导图视图（自由画布模式）

- 无限画布，网格点背景（浅色模式浅灰 / 深色模式深灰）
- 节点可拖拽（拖拽时轻微放大提示）；连线为贝塞尔曲线，选中高亮
- 连线端点吸附；空白处拖拽框选；右键空白 → "添加节点 / 适应视图"
- **自适应缩放（v1.1 P1 落地）**：内容变化（增删/折叠/拖拽/窗口缩放）导致节点超出视野时自动缩放平移容纳全部节点（fitView padding 0.12，300ms 动画）；未超出时保持当前视野不打扰；手动「适应视图」按钮仍在工具栏
- 连线标签（PRD B2.2 P1「可编辑标签」，v1.1 落地）：双击连线进入编辑，标签显示于连线中点胶囊；Enter 确认、Esc 取消、失焦提交，空白清除标签
- 工具栏（顶部浮动）：模式切换、适应视图、撤销/重做、导出（**M4 任务三 + v1.2 P2 落地**：`导出 PNG`=整图 Base64 下载、`导出 OPML`=树状大纲 XML 下载、`导出 MD`=Markdown 大纲下载；导出前自动保存未落库修改，保存失败不导出）

### 3.6 全局搜索浮层（M4 任务一落地，PRD D1/D2）

- 入口：顶部栏 🔍 搜索框 / **Ctrl+K**（§5）；浮层顶部输入框自动聚焦，**Esc** 或点遮罩关闭
- 结构：输入框 → 类型 Tab（全部/导图/条目/会话，带计数）→ 分组结果列表（全部 Tab 下按类型分节，节头「导图 · N」）
- 结果项：标题 + 命中片段（关键词 `<mark>` 高亮，后端只给纯文本片段，04 §6.3）+ 工作区上下文小字
- 跳转（PRD D2）：点击结果定位到对应工作区/导图/会话及具体条目——导图命中选中首个命中节点并居中、**目标闪烁 2s**；条目按 seq 估算所在分页并滚动定位闪烁
- 空态（§7.3）：未找到显示「未找到，试试其他关键词」；未输入时显示搜索范围提示
- 交互细节：输入 300ms 防抖；单字/短词也可搜（后端 LIKE 兜底，09 R4）

### 3.7 会话视图（时间线）

```
┌────────────────────────────────────────────────────┐
│ 会话标题 ✎              [进行中●]  09:00–11:30     │
│ 提交 12 次 · 条目 18 条 · 关联仓库 ./repo          │
│ [Git 提交时间线 ▾]  [导出 ▾]  [结束会话]           │
├────────────────────────────────────────────────────┤
│  ◉ 09:02 goal   从 0 到 1 搭建可运行骨架           │
│  ◉ 09:10 action 初始化 Spring Boot 工程…          │
│  ◉ 09:25 artifact [feat 3a1f2c] 骨架提交          │
│  ◉ 09:40 error  DB 连接失败：时区错误 → 修复       │
│  …                                                 │
│  ──────────────────────────────────────────────    │
│  [类型▾] 输入记录内容（Enter 发送，Shift+Enter 换行）│
└────────────────────────────────────────────────────┘
```

- 时间线左侧时间戳列（灰小字）；条目卡片按类型着色左缘 + 图标
- 条目卡片展开显示 Markdown 渲染（GFM：代码块/列表/引用/粗斜体，06 §9）+ 标签 + commit 徽标（点击打开详情弹层：hash/作者/时间/完整 message/变更文件 + 解绑，PRD C3.5）
- **多会话并行视图（v1.1 P1 落地）**：会话视图顶部标签栏——同时打开多个会话（每个一个标签：标题 + × 关闭），点击标签切换且各自状态保留（滚动/过滤/编辑）；「＋」回工作区继续打开其它会话（标签保留）；「← 返回」关闭当前标签（无剩余则回工作区）
- 底部"快速记录"输入框常驻：下拉选类型（默认 action）+ 文本区
- Git 提交时间线为可折叠面板，仅展示 commit 列表（hash 缩写、message、时间），与条目相互独立、可对照
- 头部导出入口（**M4 任务三完整落地**：「导出 Markdown」下载 `<标题>.md`（严格 06 §4）+「导出 JSON」下载 `<标题>.json`（06 §4A `trailmind-session-json` v1）；文件名经 Windows 非法字符清理）

### 3.8 设置页（M4 任务四/六 + v1.2 P2 导入恢复落地，07 §7/§20）

- 入口：顶部栏「⚙ 设置」按钮 / **Ctrl+,**（§5）；以主内容区视图呈现，可「← 返回」
- 结构五节：
  1. **数据库连接**：只读键值行（主机/端口/数据库/用户名/密码），密码仅显示「已配置（安全起见不展示）/未配置」——信息展示不提供改配置（首次引导配置另议，PRD E2）
  2. **外观**：主题三选一（浅色/深色/跟随系统，§6），切换立即生效并持久化（setting 表）；系统偏好变化时「跟随系统」实时跟随
  3. **默认仓库路径**：全局回退值输入 + 保存/清除；新建会话未指定仓库时按「会话 → 工作区 → 全局默认」回退继承；路径须为含 .git 目录的真实仓库（非法时后端 400 提示）
  4. **数据备份**（M4 任务六，PRD E5）：「导出全量备份」按钮 → `POST /backup/export` 下载 JSON 压缩包（zip）；导出失败时页面内提示
  5. **数据恢复**（v1.2 P2，PRD E5「导入恢复」）：「导入备份恢复」按钮触发隐藏 file input 选 zip → `window.confirm` 二次确认（全量替换不可撤销，提示先导出当前备份）→ `POST /backup/import` → 成功展示摘要（各表行数 + 恢复至 exportedAt）与「刷新页面」入口，失败页面内 `role=alert` 提示
- 深色主题：全站经 CSS 变量切换（index.css 定义浅/深两套）；导图节点为内容色板（浅底深字），深浅主题下均保持便签效果不跟随换肤

## 4. 交互细则

| 场景 | 行为 |
|---|---|
| 节点文本编辑 | 双击进入；Enter 确认；Esc 取消；Shift+Enter 换行 |
| 树状拖拽 | 拖拽节点悬停目标 500ms 高亮"成为子节点"；拖到空白根区变分支 |
| 画布连线 | 从节点边缘拖出箭头到另一节点；拖到空白取消 |
| 连线标签（PRD B2.2 P1，v1.1 落地） | 双击连线或标签进入编辑；Enter 确认、Esc 取消、失焦提交；空白清除标签 |
| 模式切换 | 顶部切换按钮；切换前若画布存在非树边，弹出三选一（见 PRD B3.3） |
| 新增时间线条目 | 类型默认保持上次选择；Enter 提交；空内容禁用提交 |
| 全局搜索 | Ctrl+K 打开；输入 300ms 防抖；Esc 关闭；点击结果跳转到对应工作区/导图/会话并定位（目标闪烁 2s，PRD D2） |
| 标签管理（M4 任务二 + v1.2 P2 批量合并） | 重命名/合并/删除/批量合并在工作区首页标签面板完成；合并需选择目标标签、批量合并需选幸存目标（其余源删除、条目改挂）；删除标签仅解除关联不删条目 |
| 按标签过滤 | 工作区页点击标签 / 会话页选择过滤下拉，即时展示命中条目；清除过滤恢复原视图 |
| 提交建议卡片 | 新 commit 出现时右下角 toast + 操作按钮（绑定当前条目/忽略）；3s 未操作自动收起，可在"未绑定提交"区找回 |
| 删除 | 侧边栏单条删除（工作区/导图/会话/标签，v1.2 P2 §24）改「带撤销的轻提示」：乐观移除 → 右下角 toast「已删除 · 撤销」→ 到期未撤销才真删、撤销即恢复；批量删除仍二次确认（多选破坏性强）。树节点删除仍提示「将删除 N 个子节点」并支持 Ctrl+Z 撤销 |
| 撤销/重做 | 全局 Cmd/Ctrl+Z / Ctrl+Shift+Z（导图操作与条目编辑均支持，MVP 至少覆盖导图） |
| 拖拽文件 | v1 不支持；未来：拖 .md 导入记录 |

## 5. 快捷键（MVP 全集）

| 快捷键 | 功能 |
|---|---|
| Ctrl+N | 新建节点（选中节点时=子节点；画布空白=新节点） |
| Ctrl+Enter / Enter | 快速记录提交 / 节点编辑确认 |
| Ctrl+K | 全局搜索 |
| Ctrl+1 / Ctrl+2 | 树状模式 / 画布模式 |
| Ctrl+E | 快速记录框聚焦 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| Ctrl+S | 手动保存（本地自动保存为主，此键用于心理安全感） |
| Ctrl+, | 打开设置 |
| Delete | 删除选中 |
| Ctrl+W | 关闭当前视图（回工作区首页） |

> 上表为默认值（**v1.2 P2 起可在设置页「快捷键」节自定义**，03 §5 落地的 10 项可改键：捕获键位 + 冲突检测 + 持久化 setting 表 `keymap` diff JSON；Ctrl+Enter/Enter 提交与 Ctrl+W 关闭视图暂不纳入可定制集）。改键后各 handler（App/MindMapEditor/SessionView）即读 keymap 生效，未改时行为不变。

## 6. 视觉规范

| 项 | 约定 |
|---|---|
| 主题 | 浅色/深色两套，默认跟随系统；MVP 提供手动切换（**M4 任务四落地**：light/dark/system 三选一） |
| 主色调 | 中性灰底 + 品牌色点缀（品牌色建议靛蓝 #4F6BFF 系，可改） |
| 字体 | 系统字体栈（中文：微软雅黑/Segoe UI；等宽：Cascadia Code） |
| 条目类型色 | goal=蓝、action=青、decision=紫、artifact=绿、error=红、test=橙、review=粉、next=黄、context=灰、prompt=靛（色板全局统一） |
| 圆角/间距 | 节点 8px 圆角；卡片 12px；间距 4 的倍数 |
| 动效 | 布局变化 150-250ms ease-out；不做过场动画 |

## 7. 空态与引导（决定产品完成度的细节，**M4 任务五全部落地**）

1. 新工作区：居中引导"新建第一张导图 / 开始第一次会话"，附 30 秒快速上手提示（导图与会话均为空时展示引导卡片，双入口按钮点击聚焦对应创建输入框；快速上手三步：新建导图 Ctrl+N 加节点 → 开始会话底部记录框 Enter 提交 → Ctrl+K 搜索/导出复盘）
2. 会话无提交：Git 面板显示"尚未检测到提交，先关联仓库或完成一次 git commit"（有仓库但 0 提交时展示）
3. 搜索无结果：显示"未找到，试试其他关键词"+ 标签快速过滤入口（「按标签浏览」按钮跳转工作区标签面板并聚焦闪烁 2s）
4. 绑定建议被忽略多次：降低提醒频率（同一会话最多 3 次，M3 任务三已实现）

## 8. 可访问性与细节

- 所有操作均有键盘路径；焦点可见
- 时间线条目对比度满足 WCAG AA（文字/背景）
- 高分屏：界面按 DPI 缩放正确，画布坐标使用独立缩放因子
