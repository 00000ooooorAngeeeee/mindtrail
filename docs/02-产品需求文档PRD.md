# 02 · 产品需求文档（PRD）

> 版本：v0.2 ｜ 状态：已定稿 ｜ 依据：01-产品定位与愿景 ｜ 面向：产品 / 开发 / agent

## 0. 需求总览

思迹 TrailMind = **项目工作区**（容器）内承载 **双模式思维导图** 与 **Git 绑定的过程记录**，并提供 **搜索与标签** 贯穿全局。MVP 全部数据本地存储（MySQL），支持导出，不依赖云。

```
┌────────────────────────────── 工作区 Workspace（= 一个项目） ──────────────────────────────┐
│                                                                                            │
│   ┌──────────────┐    ┌───────────────────────────────────────────────────┐                │
│   │  思维导图     │    │  过程记录（vibecoding 时间线）                       │                │
│   │  · 树状模式   │    │  会话 Session ── 时间线条目 Entry ── 绑定 Git commit │                │
│   │  · 自由画布   │    │  （goal/action/decision/artifact/error/next…）      │                │
│   └──────────────┘    └───────────────────────────────────────────────────┘                │
│                                                                                            │
│   全局：全文搜索 ｜ 标签管理 ｜ 导入导出 ｜ 设置                                            │
└────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 1. 名词定义

| 术语 | 定义 |
|---|---|
| 工作区 Workspace | 一个项目 = 一个工作区。包含多张导图、多个记录会话、若干标签 |
| 导图 MindMap | 一张思维导图。同一份数据可切换为「树状模式」或「自由画布模式」 |
| 节点 Node | 导图的最小单元：一段文本（可含 Markdown 备注、颜色样式） |
| 边 Edge | 节点间连接（有向）。树状模式下边构成严格树；画布模式任意 |
| 记录会话 Session | 一次 vibecoding 过程的容器，含标题、起止时间、状态、Git 仓库绑定 |
| 时间线条目 Entry | 会话内的一条记录：固定类型 + Markdown 正文 + 时间 + 可选 commit/标签 |
| 条目类型 EntryType | goal / context / prompt / action / artifact / decision / error / test / review / next（见 06 文档） |
| 提交绑定 | 一条 commit 关联到一个条目，作为该条目的"证据" |

## 2. 功能需求

### 模块 A：工作区管理（P0）

| ID | 需求 | 说明 | 验收要点 |
|---|---|---|---|
| A1 | 创建工作区 | 输入名称、可选描述、可选关联 Git 仓库路径；自动创建时间 | 创建后立即进入空工作区页 |
| A2 | 打开/切换工作区 | 最近打开列表 + 浏览选择 | 打开即恢复上次视图状态 |
| A3 | 重命名/编辑信息 | 名称、描述、关联仓库路径可改 | 改动即时生效并持久化 |
| A4 | 删除工作区 | 二次确认；MVP 不做回收站 | 删除后从列表消失 |
| A5 | 工作区首页 | 展示该工作区：导图列表、会话列表、最近更新 | 按更新时间倒序 |

### 模块 B：思维导图（P0）

**B1 树状模式（P0）**

| ID | 需求 | 说明 | 验收要点 |
|---|---|---|---|
| B1.1 | 新建导图 | 自动生成中心主题（默认"中心主题"可改） | 新建后进入树状模式编辑 |
| B1.2 | 添加子节点 | 选中节点后快捷键/按钮/双击空白添加子节点 | 新节点自动布局至正确位置 |
| B1.3 | 编辑节点文本 | 双击节点进入编辑；Enter 确认、Esc 取消；支持多行 | 编辑不打断自动布局 |
| B1.4 | 删除节点 | 删除子树；二次确认或 Ctrl+Z 可撤销 | 删除后布局重排 |
| B1.5 | 拖拽改变层级 | 拖子节点到另一节点成为其子节点；拖到根区成为分支 | 松手后自动重排并平滑动画 |
| B1.6 | 折叠/展开 | 节点图标一键折叠/展开子树 | 折叠后子节点隐藏、布局收缩 |
| B1.7 | 自动布局 | 中心向外发散的树状布局算法；同级均匀分布、无重叠 | 任意增删改后 300ms 内完成布局 |
| B1.8 | 节点样式 | 颜色主题、文字加粗；支持预设色板 | 样式随数据保存 |
| B1.9 | 画布导航 | 缩放（滚轮）、平移（拖拽空白/中键）、双击空白快速添加节点 | 500 节点下操作流畅 |

**B2 自由画布模式（P0 基础 / P1 完善）**

| ID | 需求 | 说明 | 验收要点 |
|---|---|---|---|
| B2.1 | 自由摆放 | 节点可拖到任意位置，位置被保存 | 刷新后位置不变 |
| B2.2 | 自由连线 | 任意两节点间可创建连线（有向）；连线可删除 | 连线吸附、可编辑标签（P1） |
| B2.3 | 画布缩放平移 | 滚轮缩放、拖拽平移、适应视图 | 同 B1.9 |
| B2.4 | 节点形状 | 矩形/圆角矩形/椭圆/菱形 | 形状持久化 |
| B2.5 | 自由便签 | 无文本内容的纯形状/备注卡（P1） | 可拖动可删除 |
| B2.6 | 框选 | 拖框多选、批量移动/删除/设色（P1） | 多选后操作作用于全体 |

**B3 双模式关系（P1 完善，MVP 提供基础切换）**

| ID | 需求 | 说明 |
|---|---|---|
| B3.1 | 模式切换 | 同一张导图在「树状」与「画布」间一键切换，数据完全一致 |
| B3.2 | 树状→画布 | 树状布局结果直接呈现在画布上，可继续自由调整 |
| B3.3 | 画布→树状 | 若边构成严格树 → 自动布局为树状；若非树（有环/多父）→ 提示"存在非树连线，树状视图将忽略"，提供"保持画布"或"按树重排"二选一 |
| B3.4 | 一致性 | 任一模式下的增删改，另一模式立即可见 |

**B4 导图管理（P0）**：每工作区多张导图；新建/重命名/删除/复制（P1）。列表在工作区首页。

**B5 导出（P1）**：当前导图导出 PNG（整图）、OPML（树状模式）、Markdown 大纲（P2）。

### 模块 C：过程记录（P0，产品灵魂）

**C1 会话管理（P0）**

| ID | 需求 | 说明 | 验收要点 |
|---|---|---|---|
| C1.1 | 开始会话 | 填写标题、选择关联的 Git 仓库（默认用工作区仓库）；记录开始时间 | 开始后进入时间线页 |
| C1.2 | 会话列表 | 按状态（进行中/已完成）、时间排序 | 列表显示标题/状态/条目数/起止时间 |
| C1.3 | 结束会话 | 标记完成；可写总结（写入 review 条目，见 C2） | 结束后仅可追加 review 与 note 型条目 |
| C1.4 | 删除会话 | 二次确认 | 级联删除其条目 |

**C2 时间线条目（P0）**

| ID | 需求 | 说明 | 验收要点 |
|---|---|---|---|
| C2.1 | 追加条目 | 时间线底部"快速记录"输入框：选类型 → 写正文（支持 Markdown）→ Enter 提交 | 单条记录 ≤10 秒完成 |
| C2.2 | 条目类型 | goal / context / prompt / action / artifact / decision / error / test / review / next（定义见 06） | 类型必选，默认 action |
| C2.3 | 编辑/删除 | 点击条目编辑 Markdown；可删除 | 编辑历史不追踪（MVP） |
| C2.4 | 时间戳 | 创建时间自动记录；支持手动补记时间（为"补录"场景，P1） | 时间戳精确到秒 |
| C2.5 | 插入位置 | 默认追加到末尾；支持"插入到某条之后"（P1） | — |
| C2.6 | 标签 | 每条目可打多个标签（复用模块 D） | 标签即时创建 |

**C3 Git 提交绑定（P0）**

| ID | 需求 | 说明 | 验收要点 |
|---|---|---|---|
| C3.1 | 仓库连接 | 会话/工作区绑定本地 Git 仓库（路径校验：必须存在 .git） | 非法路径给出明确提示 |
| C3.2 | 提交感知 | 会话进行中自动轮询/监听该仓库新提交（默认 5s 轮询，可关） | 新 commit 出现后 10s 内出现在"未绑定提交"区 |
| C3.3 | 手动绑定 | 在条目编辑区"绑定提交"：选择未绑定的 commit（列表含 hash、message、时间、变更文件数） | 绑定后条目卡片显示 commit 徽标 |
| C3.4 | 自动建议 | 新 commit 出现时，弹出建议卡片："绑定到当前条目？"（一键确认/忽略） | 一键绑定 <3 次点击 |
| C3.5 | 解绑/查看 | 可解绑；点击徽标查看 commit 详情（hash、作者、时间、完整 message、变更文件列表，diff 预览 P1） | 详情弹出层 |
| C3.6 | 会话 Git 全景 | 会话页头部展示：本会话期间该仓库的提交时间线（独立于条目，供对照） | 无提交时显示空态引导 |

**C4 时间线视图（P0）**

- 垂直时间线：按时间正序；条目按类型着色并显示图标
- 折叠已完成的 review/note 区块（P1）
- 无限滚动（1000+ 条目流畅）
- 会话头部显示：标题、状态、时间跨度、条目数、Git 提交数

**C5 导出（P1）**：会话导出为单个 Markdown 文件（含 YAML frontmatter，按 06 规范）与 JSON 文件。

**C6 Agent 可读性（P0 设计约束）**：条目数据结构与导出格式遵循 [06-过程记录规范](06-过程记录规范.md)，保证外部 agent 可直接解析。此为**设计约束**而非独立功能，验收标准：任意会话导出后，可按 06 文档中的解析规则完整还原条目。

### 模块 D：搜索与标签（P0）

| ID | 需求 | 说明 | 验收要点 |
|---|---|---|---|
| D1 | 全局全文搜索 | 跨所有工作区搜索：导图节点文本、条目标题/正文、会话标题；结果分类型展示 | 千级条目搜索 <1s；关键词高亮 |
| D2 | 搜索结果跳转 | 点击结果定位到对应工作区/导图/会话及具体条目 | 跳转后目标高亮闪烁 |
| D3 | 标签系统 | 标签可打在导图节点与时间线条目上；标签管理（创建/重命名/合并/删除） | 重命名标签全局生效 |
| D4 | 按标签筛选 | 会话页/工作区页按标签过滤条目；标签云视图（P1） | 过滤即时生效 |

### 模块 E：系统与设置（P0）

| ID | 需求 | 说明 |
|---|---|---|
| E1 | 本地服务管理 | 应用启动时自动拉起 Java 后端、退出时优雅关闭；异常退出可恢复 |
| E2 | 数据库配置 | 首次启动引导配置 MySQL 连接（host/port/账号/密码/库名）；默认 127.0.0.1:3306 |
| E3 | 外观设置 | 浅色/深色主题（跟随系统 P1） |
| E4 | 数据完整性 | 写操作事务化；保存防抖；崩溃重启后数据一致（见 04 文档） |
| E5 | 全量备份导出 | 导出全部数据为 JSON 压缩包（P1）；导入恢复（P2） |

## 3. 非功能需求（NFR）

| 编号 | 类别 | 要求 |
|---|---|---|
| N1 | 性能-画布 | 500 节点下缩放/平移 ≥ 45fps；节点增删改响应 ≤ 100ms |
| N2 | 性能-时间线 | 1000 条目渲染 ≤ 500ms；无限滚动流畅 |
| N3 | 性能-搜索 | 10000 条目规模下搜索响应 ≤ 1s |
| N4 | 性能-启动 | 双击图标到可交互 ≤ 3s（含后端拉起） |
| N5 | 可靠性 | 任意时刻强制退出，重启后数据不损坏（事务 + 启动自检） |
| N6 | 安全 | 后端服务仅监听 127.0.0.1；无外网调用；不发送任何遥测 |
| N7 | 兼容性 | Windows 10/11 x64；高分屏（125%/150% 缩放）正常 |
| N8 | 可维护性 | 前后端分层清晰；关键模块有单元测试；文档随代码更新 |
| N9 | 数据不锁定 | 全部核心数据可导出（Markdown/JSON/PNG/OPML） |
| N10 | 可测试性 | 后端 API 可脱离 UI 独立测试（curl/Postman 可全流程操作） |

## 4. MVP 范围界定

**MVP 包含**（P0）：模块 A（工作区）、B1 树状导图 + B2 画布基础、B4、模块 C 全部核心（C1-C4）、D1-D4、E1-E4。

**MVP 不包含，明确不做**：

- 多人协作、账号、云同步、移动端
- 导图节点挂接记录条目的**联动**（列入 P1 高价值 backlog，见 §5）
- AI 自动生成记录/摘要（v1.2 探索项）
- 富媒体（图片/附件内嵌导图节点、录音）——仅文本 + Markdown
- 插件系统、脚本化

## 5. 优先级与 Backlog

| 优先级 | 内容 |
|---|---|
| **P0（MVP）** | A 全部、B1 全部、B2 基础（2.1/2.2/2.3/2.4）、B3 基础切换（3.1/3.2/3.3 提示）、B4、C1-C4、D1-D4、E1-E4 |
| **P1（v1.1）** | B2 完善（便签/框选/连线标签）、B3 完善（画布→树状智能整理）、B5 导出、C2.4 补记时间、C2.5 插入位置、C3.6 diff 预览、C5 会话导出、E5 备份导出、**导图↔记录联动（节点挂条目、条目引用节点）**、标签云、自适应缩放 |
| **P2（v1.2+）** | AI 会话自动摘要、每周复盘报告、会话模板、工作区模板、Markdown 大纲导出、导入恢复、多标签批量操作、自定义快捷键、主题定制 |

## 6. 验收标准总览

完整可执行的里程碑验收标准见 [07-开发路线图与里程碑](07-开发路线图与里程碑.md)。本节给出**横切验收原则**：

1. **主路径闭环**：从"创建工作区 → 画导图 → 开会话 → 写条目 → 绑定 commit → 搜索到它 → 导出"全程可用，任何一步不卡壳
2. **记录极简**：新增一条记录 ≤ 10 秒（计时测试）
3. **数据不丢**：写后立即强杀进程，重启数据完好（自动化脚本验证）
4. **Agent 可解析**：按 06 文档解析导出的 Markdown，100% 还原条目类型/时间/内容/commit 绑定
5. **本地优先**：断网状态下全功能可用（除 Git 远程操作外）

## 7. 范围外/争议项说明（PM 决策记录）

| 争议项 | 决策 | 理由 |
|---|---|---|
| 导图↔记录联动是否进 MVP | **不进 MVP，列为 P1 最高优先** | 用户未选入 MVP；联动依赖两者各自成熟，先做稳底座 |
| 是否支持多会话并行 | MVP 允许多会话存在但聚焦单会话视图 | 并行编辑复杂，v1.1 再评估 |
| 记录是否全自动 | 手动为主 + Git 自动感知为辅 | 全自动质量不可控，且失去"人整理思考"的价值 |
| MySQL 是否必要 | 是（用户指定） | 尊重技术栈决策；数据模型见 05 文档 |
