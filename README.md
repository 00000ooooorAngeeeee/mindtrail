# 思迹 TrailMind

> **把思考画成图，把每一步实践写成路标。让人类和 AI 都能读懂"这个产品是怎么做出来的"。**

思迹（TrailMind）是一款面向 **vibecoder**（用 AI 辅助写代码的个人开发者）的 Windows 桌面端工具，由两大核心能力组成：

1. **思维导图**：树状导图 + 自由画布双模式，帮你把想法结构化为图；
2. **过程记录**：以"结构化时间线 + Markdown 详情"记录 vibecoding 从 0 到完整产品的每一步（目标 → 操作 → 产出 → 决策 → 下一步），并自动绑定 Git 提交记录。

两者共享同一个"项目工作区"，支持全文搜索与标签，让开发过程成为可沉淀、可检索、可交接的知识资产。

## 产品名说明

- **已定名：思迹 TrailMind**（Trail = 足迹/路径，Mind = 思维——"思维的足迹"，呼应"导图=思维、记录=足迹"双核心）
- 命名查重（2025 年核查）：中文「思迹」查无同名产品（仅有同名公司，公司≠产品）；英文 `TrailMind` 无正式商店产品（仅黑客松项目与设计概念稿）
- 否决项：`MindTrail`（App Store/Google Play/Chrome 商店多款同名应用，且中文"学迹 MindTrail"同领域）、`MindFlow`/`MindLog`/`MindPath`/`MindScribe`/`VibeTrail` 等均有正式产品使用

## 核心决策速览（详见各文档）

| 维度 | 决策 |
|---|---|
| 平台 | 仅 Windows 桌面端（MVP） |
| 架构 | 本地 C/S：Electron 前端壳 + Java (Spring Boot) 本地后端 + MySQL |
| 导图形态 | 树状自动布局 + 自由画布 双模式 |
| 过程记录 | 结构化时间线 + Markdown 详情 + Git 提交绑定 |
| 数据归属 | 全部本地存储，数据不锁定（支持导出） |
| MVP 范围 | 工作区管理、双模式导图、过程记录（含 Git 绑定）、搜索与标签、导入导出 |
